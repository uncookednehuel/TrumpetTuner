# CAD Files

[InventorDesigns](InventorDesigns) Contains the designs we made when we initially began with Autodesk Inventor. The only design in here that we used for the final prototype is the [Slide clip](InventorDesigns/SlideClip.ipt)

[FusionDesigns](FusionDesigns) Contains the designs we created after we switched to Autodesk Fusion 360. The [CaseAssembly](FusionDesigns/CaseAssembly%20v1.f3z) is our assembly file, which we only used to check interference.

[Case5](FusionDesigns/Case5%20v8.f3z) is our old case design, which we used for the first complete assembly and for prototyping, and [Case6](FusionDesigns/Case6%20v3.f3z) is our final case design, which adds geometry allowing for interface with the charger, switch, controls, and thus proper installment of the lid.
